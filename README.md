# 📚 UIU Files

> A centralized academic resource repository for United International University (UIU) students.

**UIU Files** is a student-focused repository created to organize and preserve useful academic resources for **United International University (UIU)** students in one place.

The repository contains course-related **books, lecture materials, syllabi, midterm questions, final examination papers, sample questions, and other study resources**, organized primarily by trimester, subject, and resource type.

---

## 🎯 Purpose

Finding academic materials for different courses can often be time-consuming. Students may have to search through multiple sources for:

- Course books
- Lecture slides / lecture notes
- Course outlines and syllabi
- Midterm examination questions
- Final examination questions
- Sample questions
- Previous semester resources
- Additional study materials

**UIU Files** aims to make this process easier by maintaining a structured collection of useful academic resources in a single GitHub repository.

---

## ✨ Features

### 📖 Course Books

The repository contains course-related books and reference materials where available.

Examples include:

- Textbooks
- Reference books
- Solution books
- Course-specific reading materials

---

### 📝 Lecture Materials

Course-related lecture materials can be organized and stored under the relevant subject.

This may include:

- Lecture notes
- Lecture PDFs
- Class materials
- Topic-wise resources

---

### 📋 Course Syllabus

Relevant course syllabi and course outlines can be stored alongside the corresponding subject.

This helps students quickly understand:

- Course structure
- Topics covered
- Academic scope
- Assessment-related information

---

### 🧪 Midterm Resources

The repository includes midterm-related academic materials such as:

- Previous midterm questions
- Topic-specific question papers
- Lecture-based preparation materials
- Supporting PDFs

---

### 🏆 Final Examination Resources

Final examination resources are organized separately when available.

These may include:

- Previous final examination papers
- Sample final questions
- Course-specific final preparation materials
- Past semester question papers

---
