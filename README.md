# 📚 UIU Files

> **A complete collection of my academic files, assignments, books, lecture materials, and study resources from United International University (UIU).**

**UIU Files** is my personal academic archive built throughout my journey at **United International University (UIU)**. Instead of keeping important files scattered across different devices and cloud storage, I organized everything into one structured GitHub repository for long-term preservation and easier access. This repository serves as both my personal knowledge base and a helpful resource for fellow UIU students. <Cite ref=turn0search0/>

# 📌 File Naming Convention

Use descriptive names whenever possible.

**Recommended**

```text
CSE-1111_Syllabus.pdf
CSE-1111_Mid_Fall2025.pdf
CSE-1111_Final_Spring2026.pdf
Lecture-01.pdf
Sample-Questions.pdf
```

Avoid names like:

```text
new.pdf
final2.pdf
abc.pdf
scan.pdf
```
